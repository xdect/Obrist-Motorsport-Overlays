Welches Layout in welcher Session

So funktioniert's

Unter Overlays wählst du, welche Elemente im Spiel erscheinen. Welches Layout in welcher Session gilt, legst du hier darüber fest.
Unten auf Positionieren klicken: Die Overlays erscheinen auf dem Bildschirm und lassen sich verschieben und in der Grösse ändern.
Starte iRacing im randlosen Fenstermodus. Die Overlays erscheinen automatisch, sobald du in einer Session bist.

Noch kein Stream-Overlay

Ein Stream-Overlay ist eine ganze Szene in der Grösse deines Streams. Du ordnest darauf Relative, Standings und Co. an und bindest es als eine Browserquelle in OBS ein.

Ohne iRacing zeigen die Elemente nur einen Platzhalter. Für eine Vorschau mit Daten unten rechts auf Demo wechseln.

Streckenkarte

Für alle iRacing-Strecken sind Karten hinterlegt. Nur bei einer Strecke ohne hinterlegte Karte (zum Beispiel einer ganz neuen) wird sie aus deiner Fahrt aufgezeichnet; diese Aufzeichnung kannst du hier neu starten.
