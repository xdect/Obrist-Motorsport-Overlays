Welches Layout in welcher Session

Overlays dieses Layouts erscheinen automatisch über iRacing, sobald du in einer Session bist, für die es oben gewählt ist. Starte iRacing dafür im randlosen Fenstermodus. «Auf dem Bildschirm positionieren» zeigt die Overlays sofort an, auch ohne iRacing, damit du sie an ihren Platz ziehen kannst.

Ein Stream-Overlay ist eine ganze Szene in der Grösse deines Streams. Du ordnest darauf Relative, Standings und Co. an und bindest es als eine Browserquelle in OBS ein.
