# Änderungen

Jede Version bekommt einen Abschnitt `## x.y.z`. Die Zeilen darunter erscheinen in der App unter
«Was ist neu», wenn ein Update verfügbar ist.

## 1.3.0

- Mehrere Spiel-Layouts anlegen, benennen, duplizieren und löschen
- Je ein Layout für Training, Qualifying und Rennen wählen; der Wechsel passiert automatisch mit der Session
- «Auf dem Bildschirm positionieren» zeigt ein Layout sofort an, auch ohne iRacing
- Stream-Overlays: ganze OBS-Szenen mit frei platzierbaren Elementen, je eine eigene Adresse für OBS
- Stream-Overlays nur in gewählten Session-Arten anzeigen
- Demo-Modus kann Training, Qualifying oder Rennen spielen

## 1.2.0

- Automatische Updates: OM Overlays sucht beim Start und alle 6 Stunden nach neuen Versionen
- Update mit einem Klick installieren, danach startet das Programm neu
- Während einer iRacing-Session wird nie installiert, sondern erst danach
- Version und «Nach Updates suchen» im Hauptfenster und im Infobereich

## 1.1.0

- Läuft im Hintergrund weiter, wenn das Hauptfenster geschlossen wird (Symbol im Infobereich)
- Overlays erscheinen nur in einer iRacing-Session
- Option «Mit Windows starten»

## 1.0.0

- Erste Version: Relative, Standings, Fuel, Inputs, Delta, Trackmap
- Eigenständiges Setup ohne Zusatzprogramme
